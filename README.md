# What-did-i-forgot

A modern, lightweight, and fully interactive To-Do web application built with .

This project demonstrates how to create a clean UI, manage state with `localStorage`, and build dynamic user interactions without any frameworks.

## 🚀 Features

- ➕ Add new tasks  
- ✅ Mark tasks as completed  
- 🗑 Delete individual tasks  
- 🔍 Live search  
- 🎯 Filter (All / Active / Completed)  
- 💾 Automatic saving using `localStorage`  
- 📱 Responsive design  

## 🛠 Technologies Used

- HTML 
- CSS 
- JavaScript (Vanilla)  
- Browser Local Storage API  

No frameworks. No libraries. Just pure web technologies.
